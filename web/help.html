What the four steps leave out. The commands below use the Linux x86_64 build; swap the target name for yours.

Air-gapped server

Fetch the archive and its checksum where there is internet, move both through your organisation's approved import path, then verify and unpack on the server.

curl -fsSLO https://github.com/cagojeiger/diodecam/releases/latest/download/diodecam-x86_64-unknown-linux-musl.tar.gz
curl -fsSLO https://github.com/cagojeiger/diodecam/releases/latest/download/diodecam-x86_64-unknown-linux-musl.tar.gz.sha256
sha256sum -c diodecam-x86_64-unknown-linux-musl.tar.gz.sha256
tar xzf diodecam-x86_64-unknown-linux-musl.tar.gz

macOS: "cannot be opened"

A browser download carries a quarantine mark and macOS refuses an unsigned binary. curl adds no mark, so the one-line download works as is. For a browser download, remove the mark once:

xattr -d com.apple.quarantine ./diodecam-aarch64-apple-darwin/diodecam

While sending

  • Keys: + / - change the frame rate, space pauses, q quits.
  • A larger terminal is faster: at 200×55, 1 MiB takes about 26 s. Resizing mid-transfer is fine; the phone keeps going.
  • The link is one-way. The sender cannot tell how far the phone is; the phone shows its own progress.
  • Folders: pack them first, tar czf docs.tgz docs/. Files over 64 MiB need --max-bytes.
  • diodecam -V prints the version, -h the options.

On the phone

  • Safari: Share → Add to Home Screen. The receiver then opens like an app and works offline.
  • Hold the phone sideways for a larger grid. The corner guides turn green while the grid is being read.
  • If it struggles, open ⓘ: "Stuck at" names the stage, and Copy diagnostics gives the numbers. On an iPhone Pro, choose "Back Camera" (one lens) to stop the automatic lens switch.
  • A closed tab keeps an unfinished transfer for 7 days and the received file until it is shared or replaced, a day at most. Reset clears the current one.
  • The receiver uploads nothing and never opens the file; it is saved only when you tap Share or Download. Open the receiver on this computer ›
