DiodeCam

        
One-way file transfer: point a phone camera at a terminal. No network, USB or app install.

        GitHub
      

      

        

          

            
1Install the sender

            

              
              
              
              
            

            

              
Air-gapped server default

              

                Download tar.gz
                sha256
              

              
Move both files to the server through your organisation's approved import path, then verify and unpack there.

              
sha256sum -c diodecam-x86_64-unknown-linux-musl.tar.gz.sha256
tar xzf diodecam-x86_64-unknown-linux-musl.tar.gz

            

            

              
Server with internet access

              
curl -fsSL https://github.com/cagojeiger/diodecam/releases/latest/download/diodecam-x86_64-unknown-linux-musl.tar.gz | tar xz

            

          

          

            
2Send

            
./diodecam-x86_64-unknown-linux-musl/diodecam send report.pdf

            
A larger terminal is faster: at 200×55, 1 MiB takes about 26 s. Pack folders with tar czf. Keys: +/- fps, space pause, q quit.

          

        

        

          
3Receive on a phone

          
          
Scan with the phone camera to open the receiver. In Safari, Share → Add to Home Screen makes it work offline.

          
The receiver uploads nothing and never opens the received file; it is saved only when you tap Share or Download.
